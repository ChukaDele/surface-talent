# Airtable schema — Surface Talent Jobs

Create a base called **Surface Talent — Jobs** with one table called **Jobs**. Set up these fields exactly. Case and spelling matter because the website code references them.

## Fields

| Field name    | Type             | Notes / options                                                                       |
|---------------|------------------|---------------------------------------------------------------------------------------|
| Title         | Single line text | The role title. e.g. "Operations Manager (LEAN focus)"                                |
| Subtitle      | Single line text | Optional. e.g. "Architectural Anodisers"                                              |
| Location      | Single line text | e.g. "Huddersfield"                                                                   |
| Salary        | Single line text | e.g. "£65–80k + bonus"                                                                |
| Type          | Single select    | Options: Permanent, Contract, Interim                                                 |
| Discipline    | Single select    | Options: Electroplating, Anodising, Powder coating, Heat treatment, Thermal spray, PVD / CVD, Cross-sector |
| Function      | Single select    | Options: Process and production, Quality and technical, EHS and compliance, Continuous improvement, Maintenance and controls, Commercial, Leadership |
| Seniority     | Single select    | Options: Professional, Manager, Director                                              |
| Hook          | Long text        | One-line pitch. e.g. "Take a good plant and make it run like clockwork."              |
| TheBusiness   | Long text        | Paragraph on the employer                                                             |
| TheRole       | Long text        | Paragraph on the role                                                                 |
| ThePerson     | Long text        | Paragraph on the ideal person                                                         |
| Status        | Single select    | Options: Live, Draft, Closed. Only "Live" is shown on the site.                       |
| Slug          | Single line text | Optional. URL-safe slug for future use, e.g. "ops-manager-anodiser-huddersfield"      |
